# 界面评审报告（可访问性 / 布局 / 排版 / 颜色 / 视觉打磨 / 文案）

**Scope（评审范围）**：`/`、`/console`、`/arch`、`/safety` 四个页面的完整状态（默认、加载、空状态、错误降级、大字模式、深浅两套主题），外加 `/trace/[runId]` 的回放状态。
**Coverage（覆盖情况）**：桌面 1440、窄屏 1024、320px 重排、200% 缩放、键盘 Tab 全流程、深浅主题各一遍。
**测量工具**：`scripts/ui-review.mjs`（逐元素读取渲染后的前景色与真实背景色并做 alpha 合成后计算 WCAG 比值）、`scripts/ui-audit.mjs`（运行时异常 / 横向溢出 / 可访问名称）。两条命令都可复现。

> 评审只报「有证据的问题」，不报「口味差异」。每条都给了实测值、文件位置与修复方式；修复后重新测量。

## 三、明确未做取舍（避免过度设计）

- 未引入组件库或设计系统依赖：项目只有 4 个页面 + 1 个回放页，手写 Tailwind 令牌已经够用，引依赖只会扩大部署失败面。
- 未改品牌色相：只压明度。青绿仍是主色，`#0c857a` 与 `#0d9488` 肉眼几乎无差，但对比度从 3.74 提到 4.51。
- 未给页面加 `overflow-x: hidden` 掩盖重排问题：那只是把溢出藏起来，320px 下用户依然点不到被裁掉的内容；实际改的是 `min-w-0` 与滚动容器。

## 四、测量方法自身修正过的两处假结论（写下来是因为它们同样会误导评审）

1. **用 `el.focus()` 检测焦点环** → 程序化聚焦不建立键盘模态，`:focus-visible` 不匹配，一次性假报 **89 处「没有焦点环」**。改为真实按 `Tab` 键行走后，真实不合格数为 **0**。
2. **alpha 合成写错** → 把合成结果的 alpha 直接记为 1，导致"半透明底叠半透明底"在第一步就被当作不透明，算出的背景色等于前景色（假报 1:1）。改为标准 `out = fg over bg` 后，`bg-warn/10` 类徽标的真实比值才出现（4.21–4.44）。

## 五、第二轮：视觉语言重做（"AI 味"从何而来）

第一轮把合规问题清零了，但界面本身仍然像"AI 生成的 SaaS 落地页"。这不是审美分歧，它能被拆成六条具体坏习惯——每一条都在这个仓库里真实存在过：

| "AI 味"的来源 | 原实现 | 已改为 | 为什么 |
| --- | --- | --- | --- |
| 模糊光斑 | 首页 Hero 右上 `h-72 w-72 bg-brand-200/30 blur-3xl` | 删除 | 装饰性模糊没有任何信息功能，只用来"让页面显得不空" |
| 毛玻璃导航 | `bg-surface/85 backdrop-blur-md` | 实色 `bg-surface` | 毛玻璃是模板库的默认配置；纸质界面不该透明 |
| 什么都浮起来 | 卡片 `hover:-translate-y-0.5` + `shadow-lift`（大范围弥散投影） | 只改边框色，投影压到 1px | 界面里没有任何元素真的浮在另一个元素上方 |
| 大圆角 | `rounded-2xl/3xl`（12–24px）、`rounded-full` 胶囊 | 圆角上限 10px，标签 4px | 大圆角让界面变软、变"通用"；文书是方的 |
| 品牌色铺面积 | 青色填充块、圆形头像、色块图标、青绿小标题 | 高饱和色只留主操作与当前位置（面积占比 0.18%/0.44%） | 一个颜色只能有一个含义，否则等于没有强调 |
| 聊天气泡 | `rounded-2xl rounded-br-md bg-accent-solid` 气泡 + 圆形头像 | **对话转录**：左栏位标签（问 / 守药人）+ 整行正文 + 1px 分隔线 | 气泡是社交 App 的隐喻；病历是转录体 |

同时把"层级"从投影换回细线：`--line` 1px 分隔 + 留白。数字全部换等宽 + `tabular-nums`（剂量、INR、毫秒、置信度要能竖向对齐）。

对比度在换色后**重新全量实测**：次要文字 5.19:1、主按钮白字 6.12:1、深色强调字 10.58:1，全表最低 4.59:1（门槛 4.5:1）。点击区与 320px 重排仍为 0 违规。

### 一处刻意的取舍

`--accent-*` 拆成三个令牌（`solid` / `solid-hover` / `text`）而不是复用 `brand-*` 色阶。原因：同一个青绿既要当"白字的底"，又要当"纸上的字"，深色主题下这两个用途需要相反方向（底压暗、字提亮），共用一个色阶必然有一边不合格——首轮实测里深色主按钮只有 2.49:1 就是这么来的。。
