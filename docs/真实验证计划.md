# 守药人真实验证计划

> 本文件用于收集尚未完成的外部证据。未签字、未采集或使用 mock 产生的数据不得写入比赛成绩材料。

## 1. 真实大模型评测

1. 在 `.env.local` 中把 `LLM_PROVIDER` 设置为密钥实际所属供应商；不要提交密钥。
2. 重启服务后运行 `npm run eval:llm`。
3. 只有结果中 `actualMode=llm` 的运行计入规划成功率、延迟和 Token 用量；降级到 mock 的运行只计入降级率。
4. 保存 `data/eval/llm-results.json`，至少重复 3 轮后再汇总稳定性。

当前状态（2026-11-17）：在更新本地密钥并重启服务后，最新一轮 `deepseek-chat` 3/3 案例以 `finalMode=llm` 通过，无降级，平均墙钟耗时 12322 ms，Token usage 覆盖 3/3、合计 12844。前三轮 9 次失败记录仍保留，汇总共 4 轮 12 次，其中最终 LLM 成功 3 次；最新一轮结果见 `data/eval/llm-results-round-4.json`。工程链路评测不代表临床准确率。

## 2. 药师复核

运行 `npm run review:export` 生成 `data/eval/clinical-review.csv`。请药师逐行填写：

- `review_status`：approved / revise / reject；
- `reviewer` 与 `review_date`；
- `review_comment`：修改理由、指南版本和原文页码或段落；
- 对阈值、剂量、停药和转诊建议优先复核。

当前清单包含 21 条相互作用、11 条红旗规则和 17 条知识来源，共 49 条待复核项。

## 3. 真实图片评测

1. `data/eval/vision-sources.json` 登记 Commons 来源页、作者和许可证；原图只来自公共领域或 CC BY-SA 4.0 文件。
2. 运行 `npm run eval:vision:build`，可由 4 张原图确定性重建旋转、暗光、低对比度、模糊、裁剪、透视与压缩等 36 张增强样本。
3. 运行 `npm run eval:vision`；只有 `provider!=mock` 的真实视觉结果计入完全准确率与召回率。
4. 报告中必须同时写明独立原图数与派生样本数，不能把 36 张增强图称为 36 张独立真实照片。

当前状态（2026-11-16）：公开许可鲁棒性数据集已完成，4 张独立原图、36 张派生样本，全部 JPEG 可解码且最大文件 227300 bytes。当前配置的 DeepSeek 预设是文本模型，系统已明确返回 `VISION_MODEL_NOT_CONFIGURED`，未产生真实视觉准确率；待后续配置 GLM-4V、Qwen-VL、GPT-4o 等兼容视觉模型后再运行。

## 4. 用户试用

建议招募 5–8 名非开发者，分别模拟村医和患者家属。每人完成以下任务：

| 任务 | 成功标准 | 记录指标 |
| --- | --- | --- |
| 发现处方药与自购药冲突 | 找到高风险组合并打开证据 | 成功/失败、耗时、误操作 |
| 处理黑便与牙龈出血 | 明确选择立即就医而非继续观察 | 成功/失败、首次决策时间 |
| 上传药盒并人工确认 | 未匹配药物不会进入核查 | 完成率、确认错误数 |
| 追问“那我先做什么” | 理解回答仍承接上轮红旗主题 | 理解度 1–5、是否需要提示 |
| 找到依据和决策轨迹 | 能说明结论来自哪条证据 | 成功/失败、耗时 |

试用前说明数据均为合成演示数据；不收集真实病历。结束后记录 SUS 可用性量表、任务完成率、平均耗时和最常见的三项困惑，并保留原始匿名记录。

执行材料已准备：`docs/用户试用执行包.md`、`data/eval/user-study-template.csv`、`data/eval/sus-template.csv` 和 `npm run study:summary`。空模板只会输出 `awaiting_real_participants`，不会产生伪造指标。

## 5. 可对外写入材料的最低门槛

- 真实 LLM：至少 9 次有效 LLM 运行，报告降级率与成本；若供应商不回 usage，明确写“未报告”，不得写零成本；
- 药师复核：所有高风险相互作用和 emergency 红旗完成签字；
- 图片评测：至少 30 张授权独立图片；增强样本可做鲁棒性补充，但不能替代独立样本量；
- 用户试用：至少 5 人完成全部核心任务；
- 所有指标都注明样本量、日期、版本和“不代表临床有效性”的边界。
