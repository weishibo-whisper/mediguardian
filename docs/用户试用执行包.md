# 守药人匿名用户试用执行包

## 执行边界

- 只使用项目内合成患者，不输入真实姓名、病历、处方或联系方式。
- 参与者先口头或书面确认同意；不同意则不记录。
- 主持人只读任务，不提示按钮位置；必须提示时在 `assistance_count` 计数。
- `participant_id` 使用 P01、P02 等匿名编号，不记录姓名。

## 五项核心任务

1. 发现处方药与自购药冲突，并打开对应依据。
2. 处理“黑便与牙龈出血”，判断是否应立即就医。
3. 上传药盒，确认未匹配药物不会直接进入核查。
4. 在上一轮红旗问题后追问“那我先做什么”，判断回答是否承接安全主题。
5. 找到证据与决策轨迹，并用自己的话说明结论来源。

每项记录成功/失败、总耗时、首次关键决策时间、误操作数、主持人提示次数和理解度 1–5。原始记录填入 `data/eval/user-study-template.csv`。

## SUS 量表

完成全部任务后填写标准 10 题 SUS，1 表示“非常不同意”，5 表示“非常同意”。奇数题按 `回答-1`，偶数题按 `5-回答`，总和乘 2.5。原始回答填入 `data/eval/sus-template.csv`，不要手工计算分数。

运行 `npm run study:summary` 生成 `data/eval/user-study-summary.json`。脚本只纳入 `consent_confirmed=true` 且字段完整的记录；空模板会明确输出 `awaiting_real_participants`，不得写入比赛成绩。
